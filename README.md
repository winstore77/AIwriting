# 잉크웰

브라우저에서 웹소설을 쓰고, 장면 단위로 이어 쓰는 작업실입니다.

- 서고에서 작품을 만들고 장르별로 찾습니다.
- 작업실에서 화를 나누어 원고를 씁니다. 인물과 세계 설정이 집필에 반영됩니다.
- 이어쓰기, 장면 쓰기, 선택 구간 다시 쓰기, 전개 세 갈래를 고를 수 있습니다.
- 기본 엔진은 브라우저 안에서 동작합니다. 설정에서 OpenAI 호환 API를 연결하면 같은 버튼이 그 모델로 집필합니다.
- 원고는 이 브라우저의 로컬 저장소에 남고, 마크다운으로 내보낼 수 있습니다.

```bash
npm install
npm run dev
```

개발 서버는 [http://localhost:3000](http://localhost:3000) 입니다.
